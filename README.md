# Coffee Notes — わたしのコーヒー手帖

豆・粉の商品情報と、一杯ごとの抽出条件・感想を記録する日本語の静的ウェブアプリです。
GitHub Pagesで動作します。ビルド・インストール・サーバー・APIキーは不要です。

## 公開

1. GitHubで `coffee-notes` などのリポジトリを作ります。
2. このフォルダの **中身** をリポジトリのルートに配置します。`index.html` が直下にあることを確認してください。
3. リポジトリの Settings → Pages → Build and deployment で、Sourceを **Deploy from a branch**、Branchを **main**、フォルダを **/ (root)** にしてSaveします。
4. デプロイが完了したら、Pages画面に表示されるURLを開きます。GitHubのプランによっては公開リポジトリが必要です。

公式手順：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

公開されるのはアプリ本体のコードです。試飲の記録はGitHubには送信しません。

## 使い方

- **商品手帖**：商品名、ブランド、豆／粉、産地・農園、品種、精製、焙煎度、購入先、価格・内容量、購入日・焙煎日、メモを登録します。同じ銘柄も購入ロットごとに別登録できます。
- **一杯の記録**：商品に紐づけて日付、器具、挽き方、抽出コース、使用量、投入水量、水量設定、できあがり量、湯温、時間、評価、香り、再購入の意向、メモを記録します。
- **条件をコピーして一杯**：抽出条件だけ引き継ぎ、評価・香り・感想は空にします。
- **買い物の参考**：満足度順・100g価格順などで比較。香りの傾向、酸味・苦味・コクの平均、最高評価の抽出条件、直近の再購入意向を確認できます。
- **検索**：商品名、産地、品種、購入先、メモ、記録した香りで絞り込めます。

### 評価（未評価、または1〜5）

| 項目 | 1 | 5 |
|---|---|---|
| 香りの豊かさ | 控えめ | 豊か |
| 甘みの印象 | 少ない | 多い |
| 酸味の強さ | 弱い | 強い |
| 苦味の強さ | 弱い | 強い |
| コク・口当たりの厚み | 軽い | しっかり |
| 後味の好み | 苦手 | 好き |
| バランスの好み | 苦手 | 好き |
| 総合満足度 | 低い | 高い |

専門家向けの点数ではありません。未評価は平均から除外します。酸味や苦味は強度であり、強いほど良いわけではありません。香りのタグは風味のたとえです。

NC-A58の「マグ1」は **水量の目盛り・設定** に記録します。「できあがり約180mL」と「投入した水量」を混同しないよう別項目にしています。わからない値は空欄で構いません。

## 保存・バックアップ・マージ

- `localStorage` を使用します。アプリは外部通信・アクセス解析・外部フォントを使いません。
- 保存先はブラウザ・プロファイル・端末・URLごとに独立します。GitHub Pages上の別リポジトリともパスで区別します。
- **JSONを書き出す**：商品・試飲・削除履歴を含む復元用バックアップです。端末移動はJSONを書き出して別の端末で読み込みます。
- **JSONを選択 → マージを実行**：新しいIDの記録だけ追加。同じID・同じ内容は重複しません。異なる内容は、このブラウザ／ファイルのどちらを残すか個別に選びます。更新時刻だけで勝手に上書きしません。
- マージを実行する前に、現在のデータを自動ダウンロードします。ブラウザによってはダウンロードの許可が必要です。
- 削除の履歴も残すため、古いバックアップが削除した記録を黙って復活させることはありません。競合時にファイルの内容を選ぶと明示的に復元できます。
- 同じ商品の削除と、その商品に属する試飲の編集が別端末で競合した場合は、商品と試飲それぞれの選択が必要です。商品を削除したまま試飲を残すと「削除された商品」として一杯の記録に表示されます。
- CSVは表計算用で、復元用ではありません。数式扱いされやすい文字列はプレフィックスで無害化します。
- ファイルの上限は20MB、読み込める商品＋試飲＋削除履歴は合計30,000件です。実際の保存容量はブラウザによります。
- 他のタブから変更された場合は、保存時に最新のデータを反映し、再確認を求めます。同時編集・自動同期のためのアプリではありません。

**ブラウザのデータ消去・プライベートブラウズ終了・保存容量不足に備え、定期的にJSONを書き出してください。**
GitHub PagesのURL・リポジトリ名を変える場合も先に書き出してください。

記録データをJSONとしてリポジトリへコミットしないでください。

## ファイル

- `index.html`：画面とダイアログ
- `style.css`：レスポンシブ表示
- `app.js`：フォーム、一覧、バックアップ、マージ操作
- `core.js`：スキーマ検証・データマージ・集計
- `.nojekyll`：ビルドを使わず公開
- `tests/core.test.cjs`：マージ等の回帰テスト

テスト：Node.js 18以降で `node --test tests/core.test.cjs`

ソースは通常のHTML/CSS/JavaScriptです。最新版のChrome、Firefox、Safari等での利用を想定しています。
